## 三、主要业务关联查询

### 1. 商品详情查询 (PmsPortalProductDetail)

包含以下信息：
- 商品基本信息 (pms_product)
- 品牌信息 (pms_brand)
- 商品属性列表 (pms_product_attribute)
- 属性值列表 (pms_product_attribute_value)
- SKU 库存列表 (pms_sku_stock)
- 阶梯价格列表 (pms_product_ladder)
- 满减信息列表 (pms_product_full_reduction)
- 商品可用优惠券 (sms_coupon)

### 2. 购物车商品查询 (CartProduct)

```sql
SELECT
    p.id, p.name, p.sub_title, p.price, p.pic,
    p.product_attribute_category_id, p.stock,
    pa.id AS attr_id, pa.name AS attr_name,
    ps.id AS sku_id, ps.sku_code, ps.price AS sku_price,
    ps.stock AS sku_stock, ps.pic AS sku_pic
FROM pms_product p
LEFT JOIN pms_product_attribute pa 
  ON p.product_attribute_category_id = pa.product_attribute_category_id
LEFT JOIN pms_sku_stock ps 
  ON p.id = ps.product_id
WHERE p.id = #{id}
  AND pa.type = 0
ORDER BY pa.sort DESC
```

### 3. 促销商品查询 (PromotionProduct)

```sql
SELECT
    p.id, p.name, p.promotion_type, p.gift_growth, p.gift_point,
    sku.id AS sku_id, sku.price AS sku_price,
    sku.sku_code, sku.promotion_price, sku.stock, sku.lock_stock,
    ladder.id AS ladder_id, ladder.count, ladder.discount,
    full_re.id AS full_id, full_re.full_price, full_re.reduce_price
FROM pms_product p
LEFT JOIN pms_sku_stock sku ON p.id = sku.product_id
LEFT JOIN pms_product_ladder ladder ON p.id = ladder.product_id
LEFT JOIN pms_product_full_reduction full_re ON p.id = full_re.product_id
WHERE p.id IN (...)
```

## 四、核心业务场景

### 1. 商品展示
- 商品基本信息 + 品牌 + 分类 + 属性 + SKU
- 支持多规格选择
- 展示商品详情 (PC 端和移动端)

### 2. 商品搜索
- 按关键词搜索
- 按品牌筛选
- 按分类筛选
- 多种排序方式 (相关度、新品、销量、价格)

### 3. 购物车
- 商品规格选择
- 库存校验
- 价格计算

### 4. 促销计算
- 阶梯价格 (买得越多越便宜)
- 满减活动 (满 X 减 Y)
- 会员价格 (不同会员等级不同价格)
- 限时购 (促销时间段)

### 5. 库存管理
- SKU 级别库存管理
- 锁定库存 (下单时锁定)
- 库存预警 (低库存提醒)

### 6. 商品评价
- 评论发布
- 评分系统 (0-5 星)
- 图片上传
- 评论回复
- 评论统计 (收藏数、阅读数)

## 五、数据模型特点

### SPU-SKU 模型
- **SPU (Standard Product Unit)**: pms_product 表，标准化产品单元，如"iPhone 15"
- **SKU (Stock Keeping Unit)**: pms_sku_stock 表，库存量单位，如"iPhone 15 黑色 128G"

### 属性系统
- **规格属性** (type=0): 影响 SKU 的属性，如颜色、尺寸
- **参数属性** (type=1): 不影响 SKU 的属性，如材质、产地

### 促销体系
- 促销价：直接打折
- 会员价：按会员等级定价
- 阶梯价：按购买数量打折
- 满减：满一定金额减一定金额
- 限时购：时间段内促销
