# PMS 模块数据库表关系说明

### 表冗余问题解析

pms_product_category表与pms_product_attribute_category表内容存在冗余，category一二级分类name组合起来就是attribute_category的name（服装-T恤），但使用领域不同

**对比**

维度        pms_product_category          pms_product_attribute_category

用途 		商品展示分类 				属性分组管理 

用户 		前台用户浏览 				后台管理员配置 

关注点 	    商品如何组织 				商品有哪些属性 

关系 	        树形结构 					扁平分组 

统计 		商品数量 					属性数量、参数数量



核心表还存在其他冗余，主要为名称和数量上的冗余，目的是提升查询效率，可以不用联表就能查到名称和数量的信息

## 📊 数据表总览

PMS（Product Management System）商品管理系统共包含 **18 张数据表**，主要分为以下几大模块：

### 核心表（8 张）
1. `pms_brand` - 品牌表
2. `pms_product` - 商品信息表
3. `pms_product_category` - 产品分类表
4. `pms_product_attribute` - 商品属性参数表
5. `pms_product_attribute_category` - 产品属性分类表
6. `pms_product_attribute_value` - 商品属性值表
7. `pms_sku_stock` - SKU 库存表
8. `pms_member_price` - 商品会员价格表

### 辅助表（10 张）
9. `pms_album` - 相册表
10. `pms_album_pic` - 画册图片表
11. `pms_comment` - 商品评价表
12. `pms_comment_replay` - 产品评价回复表
13. `pms_feight_template` - 运费模版表
14. `pms_product_full_reduction` - 商品满减表
15. `pms_product_ladder` - 产品阶梯价格表
16. `pms_product_operate_log` - 产品操作日志表
17. `pms_product_vertify_record` - 商品审核记录表
18. `pms_product_category_attribute_relation` - 产品分类属性关系表

## 📋 详细表结构及关系

### 1. pms_brand（品牌表）
**功能**：存储商品品牌信息，如华为、小米、苹果、耐克等

**关键字段**：
- `id` - 主键
- `name` - 品牌名称
- `first_letter` - 首字母（用于搜索索引）
- `sort` - 排序值
- `factory_status` - 是否为品牌制造商：0->不是；1->是
- `show_status` - 是否显示：0->不显示；1->显示
- `product_count` - 产品数量
- `product_comment_count` - 产品评论数量
- `logo` - 品牌 logo
- `big_pic` - 专区大图
- `brand_story` - 品牌故事

**关联关系**：
- 1 对多：`pms_product.brand_id` → `pms_brand.id` 

  主表有brand_id字段对应brand表的主键

**示例数据**：
```
id=1, name='万和', factory_status=1, product_count=100
id=6, name='小米', factory_status=1, product_count=100
id=51, name='苹果', factory_status=1, product_count=55
```

---

### 2. pms_product_category（产品分类表） 
**功能**：存储商品的分类体系，支持多级分类（树形结构）

**关键字段**：
- `id` - 主键
- `parent_id` - 上级分类 ID（0 表示一级分类）
- `name` - 分类名称
- `level` - 分类级别：0->1 级；1->2 级
- `product_count` - 产品数量
- `product_unit` - 计量单位
- `nav_status` - 是否显示在导航栏：0->不显示；1->显示
- `show_status` - 是否显示：0->不显示；1->显示
- `sort` - 排序值
- `icon` - 图标
- `description` - 分类描述

**分类层级示例**：
```
一级分类（parent_id=0）:
  id=1, name='服装', level=0
  id=2, name='手机数码', level=0
  id=3, name='家用电器', level=0

二级分类（parent_id=1）:
  id=7, name='外套', parent_id=1, level=1
  id=8, name='T 恤', parent_id=1, level=1
  id=9, name='休闲裤', parent_id=1, level=1
```

**关联关系**：
- 1 对多：`pms_product.product_category_id` → `pms_product_category.id`	

  主表product_category_id字段对应category表主键

- 自关联：`pms_product_category.parent_id` → `pms_product_category.id`

---

### 3. pms_product（商品信息表）⭐核心表
**功能**：存储商品的基本信息，是 PMS 模块最核心的表

**关键字段**：
- `id` - 主键
- `brand_id` - 品牌 ID（关联 pms_brand）
- `product_category_id` - 分类 ID（关联 pms_product_category）
- `feight_template_id` - 运费模版 ID（关联 pms_feight_template）
- `product_attribute_category_id` - 属性分类 ID（关联 pms_product_attribute_category）
- `name` - 商品名称
- `pic` - 商品主图
- `product_sn` - 货号
- `delete_status` - 删除状态：0->未删除；1->已删除（逻辑删除）
- `publish_status` - 上架状态：0->下架；1->上架
- `new_status` - 新品状态：0->不是新品；1->新品
- `recommand_status` - 推荐状态：0->不推荐；1->推荐
- `verify_status` - 审核状态：0->未审核；1->审核通过
- `sort` - 排序
- `sale` - 销量
- `price` - 价格
- `promotion_price` - 促销价格
- `stock` - 库存
- `low_stock` - 库存预警值
- `unit` - 单位
- `weight` - 商品重量（克）
- `sub_title` - 副标题
- `description` - 商品描述
- `original_price` - 市场价
- `keywords` - 关键词
- `album_pics` - 画册图片（逗号分隔）
- `detail_html` - 商品详情网页内容
- `detail_mobile_html` - 移动端详情页
- `promotion_type` - 促销类型

**关联关系**：

**主表有xx_id字段与其他表（品牌，产品分类，商品属性）进行关联**

- 多对 1：`pms_product.brand_id` → `pms_brand.id`     品牌

- 多对 1：`pms_product.product_category_id` → `pms_product_category.id`   产品分类

- 多对 1：`pms_product.product_attribute_category_id` → `pms_product_attribute_category.id`  

  **产品属性分类关联   再与attribute_category表关联后，可以知道这个商品需要哪些规格和参数**

- 多对 1：`pms_product.feight_template_id` → `pms_feight_template.id`运费

- 1 对多：`pms_product.id` ← `pms_sku_stock.product_id` sku库存

- 1 对多：`pms_product.id` ← `pms_product_attribute_value.product_id`商品属性值

- 1 对多：`pms_product.id` ← `pms_member_price.product_id`会员价格

### 4. pms_product_attribute_category（产品属性分类表）
**功能**：管理商品属性的分类，便于对不同类型的商品定义不同的属性集合，表内字段attribute_count与param_id规定了属性和参数数量，**attribute**表有product_attribute_category_id，与本表关联，形成多对一（category为1），联表可查询出具体的属性和参数

**关键字段**：
- `id` - 主键
- `name` - 分类名称
- `attribute_count` - 属性数量（type=0 的规格数量）
- `param_count` - 参数数量（type=1 的参数数量）

**示例数据**：

```
id=1, name='服装-T 恤', attribute_count=2, param_count=5
id=2, name='服装 - 裤装', attribute_count=2, param_count=4
id=3, name='手机数码 - 手机通讯', attribute_count=2, param_count=4
id=11, name='服装 - 鞋帽', attribute_count=3, param_count=0
```

**关联关系**：
- 1 对多：`pms_product_attribute.product_attribute_category_id` → `pms_product_attribute_category.id`

  attribute表有product_attribute_category_id字段与本表关联

- 1 对多：`pms_product.product_attribute_category_id` → `pms_product_attribute_category.id`

  主表有product_attribute_category_id字段与本表关联

---

### 5. pms_product_attribute（商品属性参数表）
**功能**：存储商品属性的定义，分为两类：
- **规格（type=0）**：用于描述商品的特征，如颜色、内存、尺寸等，支持自定义输入值
- **参数（type=1）**：商品的规格参数，如 CPU 型号、屏幕尺寸、分辨率等，通常是固定的

**关键字段**：
- `id` - 主键
- `product_attribute_category_id` - 属性分类 ID（关联 pms_product_attribute_category）
- `name` - 属性名称
- `select_type` - 属性选择类型：0->唯一；1->单选；2->多选
- `input_type` - 属性录入方式：0->手工录入；1->从列表中选取
- `input_list` - 可选值列表（逗号分隔，input_type=1 时有效）
- `sort` - 排序
- `filter_type` - 分类筛选样式：0->普通；1->颜色
- `search_type` - 检索类型：0->不需要检索；1->关键字检索；2->范围检索
- `related_status` - 相同属性产品是否关联：0->不关联；1->关联
- `hand_add_status` - 是否支持手动新增：0->不支持；1->支持
- `type` - 属性类型：0->规格；1->参数

**示例数据**：
```
# 服装 -T 恤的属性分类（id=1）
id=1, name='尺寸', type=0, input_type=1, input_list='M,X,XL,2XL,3XL,4XL'
id=7, name='颜色', type=0, input_type=1, input_list='黑色，红色，白色，粉色'

# 手机数码的属性分类（id=3）
id=43, name='颜色', type=0, input_type=0  # 手工录入
id=44, name='容量', type=0, input_type=1, input_list='16G,32G,64G,128G'
id=45, name='屏幕尺寸', type=0, input_type=0
id=46, name='网络', type=0, input_type=1, input_list='3G,4G'
id=47, name='系统', type=0, input_type=1, input_list='Android,IOS'
```

**关联关系**：

- 多对 1：`pms_product_attribute.product_attribute_category_id` → `pms_product_attribute_category.id`
- 1 对多：`pms_product_attribute.id` ← `pms_product_attribute_value.product_attribute_id`

---

### 6. pms_product_attribute_value（商品属性值表）
**功能**：存储具体商品的属性值，是商品与属性的关联表

**关键字段**：
- `id` - 主键
- `product_id` - 商品 ID（关联 pms_product）
- `product_attribute_id` - 属性 ID（关联 pms_product_attribute）
- `value` - 属性值（规格有多个时以逗号隔开）

**示例数据**：
```
# 商品 ID=27（华为 P20）的属性值
id=213, product_id=27, product_attribute_id=43, value='黑色，蓝色'  # 颜色
id=214, product_id=27, product_attribute_id=45, value='5.8'        # 屏幕尺寸
id=215, product_id=27, product_attribute_id=46, value='4G'         # 网络
id=216, product_id=27, product_attribute_id=47, value='Android'    # 系统
id=217, product_id=27, product_attribute_id=48, value='3000ml'     # 电池容量
```

**关联关系**：
- 多对 1：`pms_product_attribute_value.product_id` → `pms_product.id`

  本表product_id字段与主表关联

- 多对 1：`pms_product_attribute_value.product_attribute_id` → `pms_product_attribute.id`

  本表product_attribute_id字段与attribute表关联

---

### 7. pms_sku_stock（SKU 库存表）⭐重要
**功能**：存储商品的 SKU（Stock Keeping Unit）库存信息，SKU 是商品的最小库存单位

**SKU 概念**：
- 商品：华为 Mate 60 Pro
- SKU1：华为 Mate 60 Pro 黑色 256GB，价格 6999 元，库存 100 件
- SKU2：华为 Mate 60 Pro 白色 256GB，价格 6999 元，库存 50 件
- SKU3：华为 Mate 60 Pro 黑色 512GB，价格 7999 元，库存 80 件

**关键字段**：
- `id` - 主键
- `product_id` - 商品 ID（关联 pms_product）
- `sku_code` - SKU 编码
- `price` - 销售价格
- `stock` - 库存数量
- `low_stock` - 库存预警值
- `pic` - 展示图片
- `sale` - 销量
- `promotion_price` - 单品促销价格
- `lock_stock` - 锁定库存（下单未支付时锁定）
- `sp_data` - 商品销售属性（JSON 格式）

**示例数据**：
```
# 商品 ID=27（华为 P20）的 SKU 库存
id=98, sku_code='201808270027001', price=2699.00, stock=97, 
     sp_data='[{"key":"颜色","value":"黑色"},{"key":"容量","value":"32G"}]'

id=99, sku_code='201808270027002', price=2999.00, stock=100,
     sp_data='[{"key":"颜色","value":"黑色"},{"key":"容量","value":"64G"}]'

id=100, sku_code='201808270027003', price=2699.00, stock=100,
      sp_data='[{"key":"颜色","value":"蓝色"},{"key":"容量","value":"32G"}]'
```

**关联关系**：
- 多对 1：`pms_sku_stock.product_id` → `pms_product.id`

---

### 8. pms_member_price（商品会员价格表）
**功能**：存储不同会员等级的商品价格

**关键字段**：

- `product_id` - 商品 ID（关联 pms_product）
- `member_level_id` - 会员等级 ID
- `member_price` - 会员价格
- `member_level_name` - 会员等级名称

**示例数据**：
```
id=112, product_id=23, member_level_id=1, member_price=88.00, member_level_name='黄金会员'
id=113, product_id=23, member_level_id=2, member_price=88.00, member_level_name='白金会员'
id=114, product_id=23, member_level_id=3, member_price=66.00, member_level_name='钻石会员'
```

**关联关系**：
- 多对 1：`pms_member_price.product_id` → `pms_product.id`

## 📊 典型业务场景的数据流

### 场景 1：创建商品

```
1. 选择品牌 → pms_brand
2. 选择分类 → pms_product_category
3. 选择属性分类 → pms_product_attribute_category
4. 获取属性分类下的属性列表 → pms_product_attribute
5. 创建商品 → pms_product
6. 保存商品属性值 → pms_product_attribute_value
7. 保存 SKU 库存 → pms_sku_stock
8. 保存会员价格 → pms_member_price
```

### 场景 2：商品详情展示

```
1. 查询商品基本信息 → pms_product
2. 查询品牌信息 → pms_brand
3. 查询分类信息 → pms_product_category
4. 查询商品属性值 → pms_product_attribute_value
5. 查询 SKU 库存 → pms_sku_stock
6. 查询会员价格 → pms_member_price
7. 查询商品评价 → pms_comment
```

### 场景 3：商品搜索筛选

```
1. 根据分类筛选 → pms_product_category
2. 根据品牌筛选 → pms_brand
3. 根据属性筛选 → pms_product_attribute + pms_product_attribute_value
4. 获取筛选属性列表 → pms_product_attribute + pms_product_attribute_category
```

## 💡 重要说明

### 1. 属性与参数的区别
- **规格（type=0）**：影响 SKU 的属性，如颜色、尺寸、容量等，不同规格组合形成不同的 SKU
- **参数（type=1）**：不影响 SKU 的参数，如 CPU 型号、屏幕尺寸、上市年份等

### 2. SKU 的生成
SKU 由商品的不同规格组合而成，例如：
- 颜色：黑色、白色
- 容量：32G、64G
- 组合后生成 4 个 SKU：
  - 黑色 32G
  - 黑色 64G
  - 白色 32G
  - 白色 64G

### 3. 库存管理
- `stock`：实际库存
- `lock_stock`：锁定库存（用户下单未支付时锁定）
- `low_stock`：库存预警值，当库存低于此值时需要补货

### 4. 逻辑删除
PMS 模块采用逻辑删除，`delete_status` 字段控制：
- 0：未删除
- 1：已删除

## 📝 总结

PMS 模块的 18 张表构成了完整的商品管理体系：

**核心链路**：
品牌 → 商品 → 分类 → 属性 → SKU → 库存

**辅助体系**：
- 会员价格：不同会员享受不同价格
- 商品评价：用户对商品的评价和回复
- 运费模版：不同地区的运费设置
- 促销管理：满减、阶梯价等促销方式
- 操作日志：记录商品的修改历史
- 审核记录：记录商品的审核过程

这些表通过外键关系紧密关联，共同支撑起商城系统的商品管理功能。
