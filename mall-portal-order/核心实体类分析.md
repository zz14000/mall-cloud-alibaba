# mall-portal-order 核心实体类分析

## 一、实体类总览

| 实体类 | 所在模块 | 类型 | 说明 |
|--------|---------|------|------|
| OmsCartItem | order-common | 数据库模型 | 购物车项 |
| OmsOrder | order-common | 数据库模型 | 订单主表 |
| OmsOrderItem | order-common | 数据库模型 | 订单商品项 |
| OmsOrderReturnApply | order-common | 数据库模型 | 退货申请 |
| OmsOrderSetting | order-common | 数据库模型 | 订单设置 |
| CartPromotionItem | order-common | 业务扩展 | 购物车促销项（继承OmsCartItem） |
| ConfirmOrderResult | order-server | 业务聚合 | 确认订单结果 |
| OmsOrderDetail | order-server | 业务扩展 | 订单详情（继承OmsOrder） |
| OrderParam | order-server | 请求参数 | 生成订单入参 |
| OmsOrderReturnApplyParam | order-server | 请求参数 | 退货申请入参 |
| QueueEnum | order-server | 枚举配置 | 消息队列配置 |

## 二、核心实体类字段解析

### 1. OmsCartItem — 购物车项

| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long | 购物车项ID |
| productId | Long | 商品ID（关联商品服务） |
| productSkuId | Long | 商品SKU ID（关联商品服务） |
| memberId | Long | 会员ID（关联用户服务） |
| quantity | Integer | 购买数量 |
| price | BigDecimal | 添加到购物车的价格 |
| productPic | String | 商品主图 |
| productName | String | 商品名称 |
| productSubTitle | String | 商品副标题（卖点） |
| productSkuCode | String | 商品SKU条码 |
| memberNickname | String | 会员昵称 |
| createDate | Date | 创建时间 |
| modifyDate | Date | 修改时间 |
| deleteStatus | Integer | 是否删除（0未删除/1已删除） |
| productCategoryId | Long | 商品分类ID |
| productBrand | String | 商品品牌 |

```
          │CartPromotionItem │  │UmsMemberReceiveAddress│  │SmsCouponHistory  │

```

### 核心关联关系说明

| 关系 | 类型 | 说明 |
|------|------|------|
| OmsOrder → OmsOrderItem | 1:N | 一个订单包含多个订单商品项，通过 `OmsOrderItem.orderId` 关联 |
| OmsCartItem → CartPromotionItem | 继承 | CartPromotionItem 继承 OmsCartItem，附加促销计算结果 |
| OmsOrder → OmsOrderDetail | 继承+聚合 | OmsOrderDetail 继承 OmsOrder，并聚合 OmsOrderItem 列表 |
| OmsOrder → OmsOrderReturnApply | 1:N | 一个订单可有多条退货申请，通过 `OmsOrderReturnApply.orderId` 关联 |
| OmsCartItem → OmsOrderItem | 转化 | 购物车项在下单时转化为订单商品项 |
| OmsOrderSetting → OmsOrder | 配置 | OmsOrderSetting 定义订单超时规则，控制订单生命周期 |
| ConfirmOrderResult | 聚合 | 聚合 CartPromotionItem + 收货地址 + 优惠券 + 积分规则 + 金额计算 |

## 四、核心业务流转中的实体关系

### 1. 购物车 → 下单 流转

```
OmsCartItem（购物车项）
     │
     │ listPromotion() 计算促销
     ▼
CartPromotionItem（促销购物车项）
     │
     │ generateOrder() 下单
     ▼
OmsOrder（订单主表） + OmsOrderItem（订单商品项）
     │
     │ 查询详情
     ▼
OmsOrderDetail（订单详情 = OmsOrder + List<OmsOrderItem>）
```

### 2. 确认订单 流转

```
OrderParam（下单参数：cartIds + 收货地址 + 优惠券 + 积分）
     │
     │ 生成确认单
     ▼
ConfirmOrderResult
  ├── cartPromotionItemList  ← CartPromotionItem（促销购物车）
  ├── memberReceiveAddressList ← UmsMemberReceiveAddress（收货地址）
  ├── couponHistoryDetailList  ← SmsCouponHistoryDetail（可用优惠券）
  ├── integrationConsumeSetting ← UmsIntegrationConsumeSetting（积分规则）
  ├── memberIntegration        ← 会员积分
  └── calcAmount               ← CalcAmount（金额计算）
        ├── totalAmount（商品总金额）
        ├── freightAmount（运费）
        ├── promotionAmount（活动优惠）
        └── payAmount（应付金额）
```

### 3. 退货 流转

```
OmsOrderReturnApplyParam（退货申请参数）
     │
     │ 提交退货
     ▼
OmsOrderReturnApply（退货申请记录）
     │ orderId 关联
     ▼
OmsOrder（原订单）
```

### 4. 订单超时控制

```
OmsOrderSetting（订单超时配置）
  ├── flashOrderOvertime  → 秒杀订单超时关闭
  ├── normalOrderOvertime → 正常订单超时关闭
  ├── confirmOvertime     → 自动确认收货
  ├── finishOvertime      → 自动完成交易
  └── commentOvertime     → 自动好评
     │
     │ 通过 RabbitMQ 延迟队列实现
     ▼
QueueEnum
  ├── QUEUE_ORDER_CANCEL       → 订单取消队列
  └── QUEUE_TTL_ORDER_CANCEL   → 订单取消TTL延迟队列
```

## 五、跨服务关联字段

本模块作为订单服务，部分字段需要关联其他微服务：

| 字段 | 所在实体 | 关联服务 | 说明 |
|------|---------|---------|------|
| memberId | OmsCartItem, OmsOrder | 用户服务(ums) | 会员ID |
| productId | OmsCartItem, OmsOrderItem, OmsOrderReturnApply | 商品服务(pms) | 商品ID |
| productSkuId | OmsCartItem, OmsOrderItem | 商品服务(pms) | SKU ID |
| productCategoryId | OmsCartItem, OmsOrderItem | 商品服务(pms) | 商品分类ID |
| couponId | OmsOrder | 营销服务(sms) | 优惠券ID |
| memberReceiveAddressId | OrderParam | 用户服务(ums) | 收货地址ID |
| companyAddressId | OmsOrderReturnApply | 系统配置 | 公司收货地址ID |
